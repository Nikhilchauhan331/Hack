# Data used (all synthetic or public; no proprietary or client data)

| File | Nature | How it was made |
|---|---|---|
| `sample_news.csv` | Synthetic financial headlines (48 rows, some repeated on different dates) | Written by the author, generated by `src/make_sample_data.py` with random timestamps over the last ~15 business days |
| `sample_tweets.csv` | Synthetic tweet-style posts (36 rows) | Same script; informal language, $cashtags |
| `sample_transactions.csv` | Synthetic wholesale-banking portfolio (80 positions: loan, bond, derivative, equity) | Random notionals, ratings, durations, deltas (seeded, reproducible) |
| `eval_labeled.csv` | 41 hand-labelled texts for sanity-checking sentiment and event labels | Written and labelled by the author; **small and not independent of the keyword rules**, so treat as a smoke test |

Prices come from the public Yahoo Finance API through `yfinance` at run time (not stored). If offline, the code
simulates prices (`--simulate-prices` / sidebar tick box); results on simulated prices are illustrative only.

## Public datasets the engine is designed to accept (not bundled, download separately)
* GDELT DOC 2.0 API (live headlines, no key): `python src/main.py --live`
* NewsAPI.org (free key via `NEWSAPI_KEY`)
* Kaggle: *Sentiment Analysis for Financial News*, *Tweet Sentiment's Impact on Stock Returns*, *Financial Transactions Dataset*.
  Convert to `timestamp,text` (news/tweets) or the `sample_transactions.csv` schema.
